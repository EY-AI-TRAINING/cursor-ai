01 — Getting in

One sign-in unlocks the agent

Installing the binary is the easy part. What actually matters is the chain behind it: your company's identity provider authenticates you, the license server confirms your Team or Enterprise seat, and only then does Cursor unlock agent capabilities — background execution, terminal access, multi-file edits — on your machine.

02 — Interface

Four regions, one window

Everything in Cursor lives in one of four places: the editor where code actually sits, a sidebar for files, search, and source control, a command palette that appears on demand for any action by name, and a chat/agent panel where you state intent and review what the model proposes.

03 — Continuity

Nothing you've tuned gets lost

Cursor is a VS Code–compatible fork: your settings.json, keybindings, and most extensions import directly. What's new sits alongside them — a .cursor/rules directory for persistent AI instructions and workspace-level MCP configuration — additions, not replacements.

04 — Configuration

Pick the model, shape the agent

Model choice is a per-task decision — a fast, lightweight model for quick edits, a stronger reasoning model for multi-file agent work — and it sits next to a small set of agent settings that decide how much autonomy the model gets: whether terminal commands auto-run, and whether the codebase stays indexed for context.

05 — Subtopic: grounding at the workspace level

Wiring the workspace to the outside world

MCP — Model Context Protocol — is configured once per workspace and gives every agent in it live tools instead of static copy-paste: a connection to your repository, your documentation, and your ticketing system, each reachable the same standardized way.

06 — Subtopic: safety boundary

Trust is a workspace-level switch

Opening a folder Cursor hasn't seen before asks one question first: do you trust it? Say yes, and the agent can run terminal commands and edit files within the permissions you grant. Say no — or leave it unanswered — and Cursor stays read-only until you decide.
