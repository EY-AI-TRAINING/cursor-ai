01 — The mechanism

Tab predicts the next block, not the next token

Classic autocomplete finishes the word you're typing. Cursor Tab reads the surrounding code and your intent, predicts a whole edit — often several lines, sometimes a new function — and after you accept it, jumps your cursor straight to the next place that needs a matching change.

02 — Range

One mechanism, four sizes of output

The same inline generation scales from a single line to an entire scaffolded file — driven by how much you ask for in the surrounding comment or prompt. It also runs in reverse: a targeted change to one existing line, without touching anything around it.

03 — The gate

Every suggestion is a decision, not an event

Nothing a Tab suggestion generates lands until you act on it. Four outcomes are available for every single suggestion — and validating with a test run is as legitimate a response as accepting outright.

04 — Ambient vs. explicit

Tab reads the room; Chat reads what you point at

Tab's context is ambient and proximity-weighted — it leans hardest on the line you're on, then the surrounding code, then your other open tabs, then recently touched files. Chat, from Module 4, is the opposite: nothing is in scope unless you explicitly @-mentioned it.

05 — Subtopic: fit the tool to the task

Dial the interaction to the size of the job

Autocomplete settings are tunable — how eagerly Tab fires, whether it predicts multi-line blocks. But the bigger lever is judgment: small, local edits stay inline with Tab; anything that touches multiple files earns a more structured, reviewed workflow.

06 — Hands-on

Practice reading the ghost text

Module 5 closes with a single hands-on exercise — no quiz this time, just editor time.

Exercise

Accept, edit, reject, validate

Work through a small set of functions using Tab alone: accept one suggestion outright, edit a second before accepting, reject a third that goes the wrong direction, and run the tests on a fourth to validate it before committing. Then adjust the autocomplete settings and notice how the suggestions change.
