Codebase-Aware Editing & Agent Mode

Module 6 — 60 minutes. Module 5 was Tab, working near the cursor in one file. This module is the same trust model scaled up: one request, edits proposed across several files at once, grounded in a searchable index of the whole repository — with the review gate getting correspondingly more careful.

01 — Scale-up

One request, many files at once

Agent mode takes a single instruction and turns it into a coordinated set of edits across every file the feature touches — not one file extended into the next, but all of them planned together. Nothing ships until each one is reviewed.

02 — The retrieval layer

The index Agent mode searches before it edits

Before any edit happens, the repository has already been chunked and embedded into a searchable index. Every task starts with a query against that index — which is how the agent finds "where auth is handled" without you telling it the filename.

03 — Approval

Reviewing a multi-file diff is still one hunk at a time

Cross-file changes are still granular: expand any file to see its exact hunk, accept or reject that hunk alone, or move faster with accept-all once you've spot-checked the shape of the change.

04 — Tool execution

Not every command gets the same trust

Agent mode can run terminal commands to build, test, and inspect the repo — but it classifies each one first. Read-only commands run on their own; reversible changes ask you first; anything destructive is blocked until you explicitly allow it.

05 — Blast radius

Contain the blast radius before you start

In a large repository, "edit the codebase" is too wide a mandate. Scoping a task to a folder, and excluding sensitive or generated paths with .cursorignore, keeps both reads and writes fenced to where the feature actually lives.

06 — Subtopic: staying within budget

Break the task before it breaks the context budget

A large task doesn't fit in one context window any better than a large file does. Splitting it into smaller, sequential steps keeps each one fully reviewable — and each checkpoint between them is a point you can safely roll back to.

07 — Hands-on

Implement a small feature across files

Module 6 closes with a single hands-on exercise — no quiz, just Agent mode end to end.

Exercise

Ship the CSV export feature

Use Agent mode to implement the CSV export used throughout this module's diagrams — a route, a new exporter module, and its tests. Scope the task to the feature folder, review the plan and the per-file diffs before accepting, and watch which terminal commands the agent runs on its own versus which ones it asks you to confirm.
