Xebia — Cursor AI Training | AI-Assisted Software Engineering
Pre-Assessment (Module 0) — 20 Multiple Choice Questions

Purpose: This pre-assessment is administered before Day 1 training begins. It checks
baseline knowledge in the areas assumed by the course prerequisites (GenAI/LLM
fundamentals, Git/version control, testing, software design artifacts, and ticketing
tools) — not Cursor-specific mechanics, which are taught during the course itself.

Instructions: Choose the single best answer (A, B, C, or D) for each question.

--------------------------------------------------------------------------------

1. What does "LLM" stand for in the context of generative AI?
   A. Linear Learning Mechanism
   B. Logical Language Method
   C. Large Language Model
   D. Large Logic Machine

2. In the context of LLMs, a "token" is best described as:
   A. A unit of text (word/subword/character fragment) that the model processes
   B. A security credential used to authenticate API calls
   C. A unique identifier for a Git commit
   D. A single line of code generated by the model

3. What is a "context window" in an LLM?
   A. The visible area of the code editor
   B. The time period during which a model's training data was collected
   C. The set of file extensions supported by an IDE
   D. The maximum amount of text (tokens) a model can consider at once when
      generating a response

4. "Hallucination" in generative AI refers to:
   A. The model running out of memory
   B. The model generating plausible-sounding but factually incorrect or
      unsupported output
   C. A visual glitch in the IDE
   D. The model refusing to respond to a prompt

5. Why is generative AI output generally non-deterministic, unlike traditional
   software?
   A. The same prompt can produce different outputs across runs due to how the
      model samples/generates text
   B. It always produces the exact same output for the same input, like a compiler
   C. Non-determinism only affects image generation, not text
   D. It depends solely on the user's internet connection speed

6. What is a "knowledge cutoff" for an LLM?
   A. The maximum file size the model can read
   B. The limit on the number of API calls allowed per day
   C. The point in time after which the model has no training data or awareness
      of events
   D. The moment a coding session ends

7. In prompt engineering, what does "few-shot prompting" mean?
   A. Asking the model a very short question
   B. Providing a small number of examples in the prompt to guide the model's
      output
   C. Limiting the model to a few tokens in its response
   D. Running the same prompt multiple times

8. Which best describes the key difference between traditional deterministic
   software and generative AI systems?
   A. Traditional software is always faster
   B. Generative AI cannot be tested at all
   C. There is no meaningful difference
   D. Traditional software follows fixed logic/rules producing predictable
      output; generative AI produces probabilistic output that can vary and
      requires verification

9. In Git, what is the primary purpose of a "branch"?
   A. To permanently delete old code
   B. To allow isolated, parallel lines of development without affecting the
      main codebase
   C. To compress repository size
   D. To automatically deploy code to production

10. What does "committing" changes in Git do?
    A. Records a snapshot of staged changes into the repository's history
    B. Deletes the changes permanently
    C. Sends the code directly to production
    D. Merges two branches automatically

11. What is the main purpose of unit testing?
    A. To test the entire deployed application end-to-end in production
    B. To measure server response time under load
    C. To document the codebase for new developers
    D. To verify that an individual function or component behaves correctly in
       isolation

12. What is API testing primarily concerned with validating?
    A. The visual layout of a web page
    B. The speed of the developer's typing
    C. The requests, responses, and behavior of an application's programming
       interface (endpoints, status codes, payloads)
    D. The color scheme of the user interface

13. A tool like PyTest is used for:
    A. Writing and running automated tests for code
    B. Managing Git branches
    C. Designing UML diagrams
    D. Tracking project tickets

14. Why is having a test suite important when using AI to refactor or generate
    code?
    A. Tests are optional and rarely useful
    B. Tests provide a way to validate that AI-generated or refactored code
       still behaves correctly
    C. Tests replace the need for code review entirely
    D. Tests are only useful for front-end code

15. What does an SRS (Software Requirements Specification) document typically
    capture?
    A. The final deployed source code
    B. The list of Git commits for a release
    C. The functional and non-functional requirements a system must satisfy
    D. The personal notes of individual developers

16. In software design, an "API contract" refers to:
    A. A legal agreement between two companies
    B. A Git commit message convention
    C. A billing agreement for cloud API usage
    D. The defined structure of requests/responses (inputs, outputs, data
       formats) that an API commits to support

17. What is the purpose of an architecture diagram in software design?
    A. To track team velocity in sprints
    B. To visually represent system components and how they interact
    C. To list all bugs found in testing
    D. To generate automated test cases

18. In Agile/ticketing tools like Jira or Azure DevOps, a "ticket" (work item)
    typically represents:
    A. A discrete unit of work, such as a task, bug, or user story, tracked
       through a workflow
    B. A compiled binary of the application
    C. A Git repository
    D. A server configuration file

19. Which of the following best describes an "IDE" (Integrated Development
    Environment)?
    A. A cloud storage service for backups
    B. A type of database management system
    C. A network security protocol
    D. A software application that combines tools like a code editor, debugger,
       and build automation to support software development

20. Which statement best reflects a sound general principle when adopting
    AI-assisted software engineering practices?
    A. AI-generated output should be trusted and merged without review since it
       is always correct
    B. AI tools eliminate the need for requirements or specifications
    C. AI-assisted output should still be verified, tested, and reviewed like
       any other engineering artifact
    D. AI-assisted development removes the need for version control
