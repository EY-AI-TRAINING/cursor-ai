📌 Recap

What to carry into Module 4

  • Installing Cursor and connecting your enterprise account is what enables Agent capabilities — a personal/free account won't have them.
  • The interface has four zones worth knowing cold: Editor, Sidebar, Command Palette, and the Ask/Chat/Agent panel.
  • VS Code keybindings, theme, extensions, and snippets import directly — you're not starting from zero.
  • Model choice is a speed-vs-depth trade-off; basic agent settings decide how much runs before it checks in with you.
  • MCP servers (repo, docs, ticketing) are connected once per workspace and shared by anyone who opens it.
  • Workspace trust is a dial — Restricted → Trusted → Trusted+Auto-run — each level unlocking more autonomous action.
