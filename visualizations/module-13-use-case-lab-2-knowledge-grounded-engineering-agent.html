Activity 3 / Use rules/skills to constrain the agent's behavior

The config states intent. The rule enforces it.

A repo-level rule is what actually blocks the ungrounded behaviors — not just the agent's good intentions. Sort what it allows from what it blocks.

2globs: agents/grounded-*.agent.yml
3---
4- Only answer engineering facts from a connected source.
5- Every factual claim must include a [source: ...] citation.
6- If no connected source supports the answer, say so — never infer.
