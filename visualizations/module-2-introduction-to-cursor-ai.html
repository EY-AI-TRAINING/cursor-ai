01 / What is Cursor AI

Not an IDE with AI bolted on — AI-native, end to end

Cursor is a full code editor (a fork of VS Code) where chat, inline generation, and autonomous agents share one deep, continuously-updated view of your codebase — instead of AI living in a sidebar plugin that has to be told what to look at every time.

Same task, two workflows: "Add pagination to the users list endpoint"

⌨️ Traditional IDE
1Open the file manually and read through existing code to find the pattern to follow.
2Search docs / Stack Overflow in a browser tab for a pagination approach.
3Write the code by hand, tabbing between files to check conventions.
4Write tests by hand, run them, fix what fails.
5Re-read the diff yourself to check it matches team style.
🖱️ Cursor AI
1Ask "@UsersController how does list() work today, and how should pagination fit our style?"
2Agent mode reads related files and proposes a multi-file diff (controller + DTO + tests).
3Tab-completion fills in boilerplate as you review, context-aware to what's around it.
4Agent runs the test suite in the terminal itself and fixes a failing assertion.
5You review the diff, approve it — adjusting a rule in AGENTS.md if it should apply next time too.

04 / Local development vs. delegated/background agent execution

Two ways to run the same agent

A conceptual overview — the mechanics (Git, CI/CD, cloud agents, ticketing hand-offs) get a full day of their own later in this course.

💬1 · You askYou type a request directly in your open workspace.
👀2 · You watchThe agent works in view, step by step, inside the editor you're looking at.
✋3 · You steerYou can pause, redirect, or approve each step before it continues.
✅4 · Done, liveYou're at your desk the entire time — tight feedback loop, good for exploratory work.
📨1 · You hand offYou describe a task and delegate it — no need to keep watching.
☁️2 · It runs remotelyThe agent works in the background — a separate environment, not your open editor.
⚙️3 · You keep workingMeanwhile you're free to do something else — including delegate more tasks in parallel.
🔔4 · It reports backYou get notified at a checkpoint or completion, then review the finished diff/PR.

Same underlying agent, different trade-off: local favors a tight, interactive feedback loop; background favors throughput — freeing you up for longer-running or lower-priority tasks.
