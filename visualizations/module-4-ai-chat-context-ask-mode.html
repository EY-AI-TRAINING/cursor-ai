📌 Recap

What to carry into Module 5

  • Chat answers are only as good as the context behind them — scope matters more than which question you ask.
  • @-mentions (file, folder, docs, symbol) are how you hand Cursor exactly the right context, deliberately.
  • Ask, Chat, and Agent are three points on a risk/autonomy spectrum, not three unrelated tools.
  • Too little context gives a generic answer; too much dilutes signal and strains the context window from Module 1.
  • Long threads degrade — start a new chat scoped to the task instead of dragging an old one along.
  • A strong analysis prompt scopes with @-mentions, asks something specific, and states the output format/constraints you want.
