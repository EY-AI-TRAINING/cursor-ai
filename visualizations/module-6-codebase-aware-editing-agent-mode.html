📌 Recap

What to carry into Module 7

  • Agent mode reads across your repo and proposes coordinated, multi-file changes — not single completions.
  • Cursor's codebase index lets it find relevant code by meaning, not just literal keyword matches.
  • A multi-file change set deserves the same scrutiny as any PR — review every file's diff before approving.
  • Commands Agent runs are gated by risk: safe, inspectable ones can auto-run; destructive ones should ask first.
  • Scope matters — a narrower edit means a smaller blast radius and a change set you can actually review.
  • Big tasks get decomposed into context-window-sized, reversible steps — that discipline is what makes Agent mode trustworthy.
