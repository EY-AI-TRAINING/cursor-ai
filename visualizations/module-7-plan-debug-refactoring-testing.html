📌 Recap

What to carry into Module 8

  • Plan mode makes you review a written plan before any code changes — explore → plan → review → implement.
  • Debug mode forms a hypothesis and tests it, rather than guessing at a fix from the symptom alone.
  • Natural-language refactor instructions work on legacy code too — explore and understand behavior first, then change its shape.
  • A pasted stack trace is enough context for AI to explain a failure and propose a fix — you still approve it.
  • Tests and fixes run in a loop: write the test, run it, let a red result drive the next fix, rerun until green.
  • Every AI refactor gets validated against the existing test suite — test failures are context for the next attempt, not just a pass/fail signal.
